# Code of Conduct

We want this project to be useful and safe to participate in. That means being direct without being
cruel, and disagreeing without making people feel unwelcome.

## What we expect

- **Be constructive.** Critique code and ideas, not the person behind them.
- **Be clear.** Ask questions when something is ambiguous; say when you do not know.
- **Be respectful of time.** Search existing issues before filing duplicates; keep threads on topic.
- **Handle security responsibly.** Report vulnerabilities through a
  [private advisory](https://github.com/egemenyildiz/herdr-slack/security/advisories/new), not a
  public issue.

## What we do not allow

- Harassment, threats, slurs, or sustained personal attacks
- Discrimination based on identity or background
- Sexualized content or unwelcome sexual attention
- Doxxing, sharing private correspondence without consent, or other privacy violations
- Spam, bad-faith disruption, or pile-ons

## Scope

This applies everywhere the project is maintained: GitHub (issues, PRs, discussions), and any space
where you represent the project or its community.

## Enforcement

Maintainers may warn, moderate, or remove contributions, and temporarily or permanently block
participants who violate this code.

To report a concern, open a GitHub issue if it can be public, or contact the maintainer through a
[private security advisory](https://github.com/egemenyildiz/herdr-slack/security/advisories/new)
when it cannot. Reports are handled in confidence; we do not retaliate against good-faith reporters.

Maintainers who fail to uphold this code may be replaced by the project owner.
