# herdr-slack

Drive your local [herdr](https://herdr.dev) agents from Slack — browse every agent, open a session,
answer a blocked prompt, or start a new agent, from your phone.

No relay, no tunnel, no public URL, no backend. Your machine dials out over Slack
[Socket Mode](https://docs.slack.dev/apis/events-api/using-socket-mode/); nothing dials in.

> **Status: in development.** Not yet usable. See [`docs/00-plan.md`](docs/00-plan.md).
